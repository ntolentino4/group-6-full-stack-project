# Application Style Guide

A central stylesheet and style guide for our Personal Expense Tracker application.

---

## 🎨 Color Palette

The following colors should be used consistently throughout the application.

| Color Name      | Hex Code | Usage                  |
| --------------- | -------- | ---------------------- |
| Granite         | #627264  | Primary text, headings |
| Celadon (Light) | #A1CDA8  | Main background        |
| Celadon (Mint)  | #B5DFCA  | Cards, sections        |
| Frozen Water    | #C5E7E2  | Highlights, borders    |
| Lilac Ash       | #AD9BAA  | Buttons, accents       |

---

## 🔤 Typography

### Font Family

- **Primary Font:** Arial, sans-serif

### Font Sizes

| Usage           | Size      |
| --------------- | --------- |
| Headings(h1,h2) | 32px/24px |
| Body Text       | 16px      |
| Small Text      | 14px      |

---

## 📐 General Styling Rules

- Use consistent spacing and padding.
- Maintain sufficient contrast for readability.
- Use accent colors sparingly for emphasis.
