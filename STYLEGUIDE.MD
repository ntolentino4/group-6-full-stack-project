# Application Style Guide

## **Project:** Personal Expense Tracker

## Color Palette

These colors are defined to ensure a consistent look and feel while maintaining accessibility standards.

| Color Name       | Hex Code  | Preview | Usage                  |
| :--------------- | :-------- | :-----: | :--------------------- |
| **Granite**      | `#3D473E` |   ⬛    | Primary text, headings |
| **Celadon (L)**  | `#A1CDA8` |   🟩    | Main background        |
| **Celadon (M)**  | `#B5DFCA` |   🟩    | Cards, sections        |
| **Frozen Water** | `#C5E7E2` |   🟦    | Highlights, borders    |
| **Lilac Ash**    | `#7D6478` |   🟪    | Buttons, accents       |
