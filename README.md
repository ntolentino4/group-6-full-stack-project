## Project General Description 

Three High-Level User Stories:

Story 1:  
"As a user, I want to securely register and log in to my account so that my financial data remains private and accessible only to me".

Story 2:  
"As a user, I want to record my daily expenses with amounts, categories, and dates so that I can maintain an accurate history of my spending habits". 

Story 3:  
"As a user, I want to view a monthly summary and category breakdown of my expenses so that I can identify patterns and better manage my personal budget"
